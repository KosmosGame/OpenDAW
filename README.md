# OpenDAW
OpenDAW is a lightweight and beginner friendly digital audio workstation that is opensource and built to make music production accessible.
It was built to be a lightweight and simple music production program while still giving users the tools they need to create, edit, record and arrange music.

## Features

- Multitrack audio editing
- MIDI piano roll
- Virtual instruments
- Chord maker
- Drum machine
- Audio effects
- Volume and pan automation
- Mixer
- Looping and markers
- MIDI input
- Project saving and loading
- Audio export
- Python plugin system
